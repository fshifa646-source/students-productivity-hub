🎓 Student Productivity Hub

A modern and responsive web application designed to help students organize their academic activities, manage daily tasks, track assignments, plan study schedules, and monitor their productivity in one place.

🌐 Live Demo

Website: https://productivitymaxer.lovable.app/

📌 About the Project

Student Productivity Hub is a student-focused productivity platform developed as part of a Software Engineering academic assignment.

The main goal of this project is to make student life more organized and productive by providing useful academic management tools in a single platform.

✨ Features

- 📊 Dashboard – View tasks, assignments, and daily productivity.
- ✅ To-Do List – Add, edit, delete, and manage daily tasks.
- 📅 Study Planner – Organize daily and weekly study schedules.
- 📚 Assignment Tracker – Track assignments, deadlines, and completion status.
- 📝 Study Notes – Create, edit, save, and manage study notes.
- 📈 Progress Tracker – Monitor daily and weekly productivity.
- 📱 Responsive Design – Works on mobile, tablet, and desktop.

🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- HTML
- CSS
- JavaScript
- Local Storage

🎯 Project Objective

The objective of this project is to develop a simple and user-friendly productivity platform that helps students improve time management, organize academic responsibilities, and maintain consistent study habits.
